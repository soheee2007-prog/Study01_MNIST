# 손글씨 숫자 인식 (MNIST CNN)

마우스로 숫자(0~9)를 그리면 PyTorch로 학습한 합성곱 신경망(CNN)이 어떤 숫자인지 알려주는 프로그램입니다.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `model.py` | CNN 모델 정의 (학습과 인식에서 함께 사용) |
| `train.py` | MNIST 데이터셋으로 모델을 학습하고 가중치를 `mnist_cnn.pt`로 저장 |
| `app.py` | 마우스로 숫자를 그리면 인식해 주는 프로그램 (tkinter) |
| `mnist_cnn.pt` | 학습된 가중치 파일 |
| `make_icon.py` | 바로가기와 앱 창에 쓸 아이콘(`icon.ico`)을 만드는 코드 |
| `icon.ico` | 앱 아이콘 |
| `data/` | MNIST 데이터셋 (학습 시 자동 다운로드) |

## 설치

Python 3.10 이상이 필요합니다.

```bash
pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
pip install pillow numpy
```

> NVIDIA GPU가 있다면 [PyTorch 공식 사이트](https://pytorch.org/get-started/locally/)에서 CUDA 버전을 설치하면 학습이 더 빨라집니다.

## 사용 방법

### 1. 학습

```bash
python train.py
```

- MNIST 데이터를 `./data` 폴더에 내려받은 뒤 5에폭 동안 학습합니다.
- 에폭마다 시험 정확도를 출력하고, 가장 좋은 가중치를 `mnist_cnn.pt`로 저장합니다.
- CPU 기준 에폭당 약 3분 정도 걸립니다.

### 2. 손글씨 인식

```bash
python app.py
```

- **왼쪽 마우스 버튼**을 누른 채 끌어서 숫자를 그립니다.
- 마우스를 떼면 자동으로 인식하여 결과, 확신도, 0~9 각각의 확률 막대를 보여줍니다.
- **[지우기] 버튼**, **오른쪽 클릭**, **Delete 키**로 그림을 지웁니다.

### 3. 바탕 화면 바로가기 (윈도우)

바탕 화면의 **"손글씨 숫자 인식"** 아이콘을 더블 클릭하면 검은 명령 창 없이 앱만 열립니다.

- 바로가기는 `pythonw.exe`(콘솔 창이 없는 파이썬)로 `app.py`를 실행합니다.
- 아이콘은 `icon.ico`이며, `python make_icon.py`로 다시 만들 수 있습니다.
- 작업 표시줄에 고정하려면 바로가기를 **마우스 오른쪽 클릭 → (추가 옵션 표시) → 작업 표시줄에 고정**을 누릅니다.

## 모델 구조

```
입력 (1×28×28)
 → [합성곱 3×3, 32] → 배치정규화 → ReLU
 → [합성곱 3×3, 32] → 배치정규화 → ReLU → 최대풀링  (32×14×14)
 → [합성곱 3×3, 64] → 배치정규화 → ReLU
 → [합성곱 3×3, 64] → 배치정규화 → ReLU → 최대풀링  (64×7×7)
 → 펼치기 → 완전연결 128 → ReLU → 드롭아웃 0.5
 → 완전연결 10 (숫자 0~9)
```

- 손실 함수: 교차 엔트로피
- 최적화: Adam (학습률 0.001, 에폭마다 0.7배 감소)
- 데이터 증강: 무작위 회전(±10°), 이동(±10%), 크기 변화(0.9~1.1배)

## 인식 정확도를 높이는 전처리

그림판에 그린 숫자는 MNIST 이미지와 크기·위치가 다르기 때문에, 인식 전에 MNIST와 같은 형식으로 바꿉니다.

1. 색 반전 (흰 배경/검은 글씨 → 검은 배경/흰 글씨)
2. 글씨가 있는 부분만 잘라내기
3. 가로세로 비율을 유지하며 20×20 크기에 맞추기
4. 28×28 바탕의 가운데에 배치
5. 무게중심이 정중앙에 오도록 이동
6. 학습 때와 같은 평균·표준편차로 정규화
